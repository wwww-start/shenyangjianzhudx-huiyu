## 学习目标与生活例子

理解 AI、机器学习和深度学习的关系，能手算一个神经元；分清训练和推理。这部分介绍原理和应用，不要求部署或训练模型。

把识别水果想成学习一条判别规则：传统程序员明确写“颜色达到某阈值且圆度足够”，机器学习则从带标签的例子中估计参数。两者都需要人定义任务、输入、评价方法和应用边界。

## 三个同心概念

人工智能是让计算系统执行通常需要智能的任务这一广泛领域，包括搜索、规划、规则推理与学习等。机器学习是其中从数据改善行为的一类方法。深度学习使用多层可学习表示，属于机器学习。不是所有 AI 都是大语言模型，也不是所有机器人都必须使用 AI。

## AI 的进化史：方法、数据与算力一起变化

| 时间 | 代表节点 | 解决了什么，又留下什么 |
|---|---|---|
| 1943 | McCulloch 与 Pitts 的形式神经元 | 用数学结构讨论神经计算，距离真实大脑仍很远 |
| 1950 | Turing 讨论机器智能 | 把“会思考吗”转化为可讨论的行为问题 |
| 1956 | Dartmouth 夏季研究项目 | “人工智能”作为研究方向形成标志性起点 |
| 1950s–1970s | 符号推理、搜索与早期学习 | 显式规则可解释，但开放世界规则难写全 |
| 1970s–1980s | 专家系统 | 编码领域经验，但维护与泛化困难 |
| 1970s、1980s 后期等 | 多轮资金与期待退潮 | 通常称 AI 寒冬，时间划分并不唯一 |
| 1986 | 反向传播研究受到广泛关注 | 多层网络训练有了重要方法；算法不是凭空在一年出现 |
| 1990s–2000s | 统计学习、更多数据与计算 | 以数据和评测推动识别任务 |
| 2012 | AlexNet 在 ImageNet 上的突破 | 卷积网络、GPU、数据规模结合显示优势 |
| 2017 | Transformer | 以注意力为核心，支持新的序列建模路线 |
| 2020s | 大规模预训练、生成式模型与工具应用 | 能力扩展，也带来事实性、评估和可靠性问题 |

历史不是新方法把旧方法全部淘汰。机器人仍大量使用经典控制、状态机与规划算法，深度模型只是系统的一部分。

## 神经元：加权求和，再经过非线性

$$z=\sum_i w_ix_i+b,\qquad a=\sigma(z)$$

输入 $x$ 是数值特征；权重 $w$ 决定每个输入的影响；偏置 $b$ 平移判别边界；激活函数引入非线性。Sigmoid 将值映射到 0～1，ReLU 为 $\max(0,z)$。输出在 0～1 并不自动保证是校准良好的概率。

<Figure name="neural" caption="原创神经网络结构示意：输入经带权连接进入隐藏层，再产生输出。图中的圆是数学计算单元，不是生物神经元实物。" />

```python
from math import exp
x1, x2 = 0.6, 0.2
w1, w2, bias = 1.0, -0.5, -0.2
z = w1 * x1 + w2 * x2 + bias
output = 1.0 / (1.0 + exp(-z))
```

第 1 行导入指数函数；第 2 行输入两个人为选择的特征；第 3 行设定参数；第 4 行得到 z=0.3；第 5 行得到约 0.574。这里没有训练，参数由人给定，不应把输出当成真正的水果识别结果。

## 训练、推理、损失与梯度下降

**推理**是参数固定时计算输出。**训练**是用样本、目标值和损失函数反复更新参数。例如平方误差：

$$L=\frac12(\hat y-y)^2,\qquad w\leftarrow w-\eta\frac{\partial L}{\partial w}$$

学习率 $\eta$ 决定每步走多远。梯度指出局部增加损失最快的方向，沿负梯度更新通常尝试减小损失，但不保证每步都下降或找到全局最优。

反向传播用链式法则，把输出误差对参数的导数逐层算回来。例如线性输出 $\hat y=wx+b$ 时，$\partial L/\partial w=(\hat y-y)x$。反向传播负责算梯度，优化器负责用梯度更新参数，它们不是同一个步骤。

数据要区分训练、验证和测试；训练表现很好但新样本差，可能是过拟合。没有代表性数据、明确指标与独立评估，模型复杂并不等于可靠。

## 常见错误与思考题

把神经网络理解成复制大脑；把输出小数当必然正确的概率；把测试数据偷偷用于反复调参；把损失降低等同于现实任务已经安全可靠。

<details><summary>如果网络每层都只做线性变换，多堆几层会怎样？</summary>多个线性/仿射变换仍可合并成一个仿射变换，表达能力并不会因此获得一般的非线性边界。激活函数很关键。</details>
<details><summary>训练与推理哪个需要标签？</summary>监督训练通常需要用于损失计算的目标标签；推理面对新输入时通常没有该输入的正确答案标签。自监督等训练方式可以从数据构造目标。</details>
