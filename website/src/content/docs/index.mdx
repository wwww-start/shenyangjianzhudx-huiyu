## 推荐学习路线

| 阶段 | 先回答的问题 | 动手证据 |
|---|---|---|
| 入门 | 电平与二进制为什么能表示信息？ | 单步观察取指、译码、执行 |
| 外设 | 程序怎样改变引脚？ | 比较推挽、开漏和 PWM |
| 控制 | 为什么同样的占空比不总是同样的速度？ | 调节 PID 并导出响应数据 |
| AI | 模型如何从样本中学到关系？ | 调权重，观察神经元输出 |

每次学习建议采用“读一节 → 看一张图 → 运行一个例子 → 回答一道题”。正文保持连续阅读，所有动态互动均放在独立实验页。

## 教材与工程的边界

原仓库的 Word、Markdown、C 示例全部保留。[原教材与学习资源](/shenyangjianzhudx-huiyu/resources/)集中提供下载、出处和视频链接。网页仿真是教学模型，参数不是实际电机辨识结果。标准库示例需要按开发板接线、时钟与型号集成，不是已经验证过的整板工程。

互助，开源，共享是科学真正的精神。
