## 网络、DNS 与 VPN

DNS 把域名等查询映射到相应记录，例如 A/AAAA 地址记录；浏览器拿到地址后再建立连接。DNS 不是网页内容本身。VPN 通过隧道机制连接网络端点，具体协议可提供加密和身份验证；它不自动保证匿名或让终端免受攻击。**本文VPN只做讲解科学原理。** 详细原讲义见第 17 章。

## Linux 与 Windows：先学共同概念

两者都有文件、进程、权限、网络和图形/命令行工具。Linux 常见于服务器、开发环境和机器人上位机；Windows 适合本课 Keil 等工具环境。不能简单认为一个“只能命令行”、另一个“不能编程”。

| Linux 命令 | 作用 | 例子 |
|---|---|---|
| `pwd` | 查看当前目录 | `pwd` |
| `ls` | 列目录 | `ls -l` |
| `cd` | 切换目录 | `cd ~/projects` |
| `mkdir` | 创建目录 | `mkdir lesson` |
| `cp` | 复制文件 | `cp main.c main_backup.c` |
| `cat` / `less` | 查看文本 | `less README.md` |
| `grep` | 搜索文本 | `grep -n PID main.c` |
| `ps` | 查看进程 | `ps aux` |

先在自己的练习目录操作，理解路径与大小写；不要机械复制需要管理员权限或删除文件的命令。更多内容见原讲义第 18 章。
