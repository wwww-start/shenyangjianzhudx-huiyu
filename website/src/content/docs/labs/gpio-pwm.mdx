## 原理与原仓库呼吸灯代码

在理想高电平 3.3 V、低电平 0 V 的情况下，周期平均电压为 $\bar V=3.3D$，D 取 0～1。RC 滤波满足 $\tau\frac{dv}{dt}+v=v_{PWM}$，其中 $\tau=RC$。上图按每段恒定输入的指数解计算周期稳态波形，并非手画数据。

总览用青色包络和抽样短柱表现整轮变化，下方方波用固定电压幅度、变化的脉冲宽度表现 PWM。图中 24 个代表周期便于观察趋势，并不是把 1 kHz 降成每轮 24 次开关。时间游标、当前占空比、灯光及局部波形使用同一个模型同步更新。

网页默认使用平滑呼吸：$D(t)=\frac{1-\cos(2\pi t/T_b)}{2}$，$T_b$ 为一轮呼吸时间。这是占空比包络，不是滤波器输出或亮度实测曲线。也可切换“原代码线性渐变（三角）”，比较两种变化方式。

原仓库 `PWM_Demo_Start()` 建立 1 kHz PWM；`PWM_Demo_Poll()` 每 20 ms 将比较值增加或减少 10，从 0 到 999 后折返，对应线性渐变。完整代码和逐段解释见[正文](/shenyangjianzhudx-huiyu/stm32/gpio-pwm/#原-pwm-模块与关键行)。网页一轮呼吸默认 4 秒，与该示例的大致节奏一致；网页理想端点为 100%，原模块最大为 99.9%。
