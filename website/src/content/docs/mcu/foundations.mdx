## 学习目标

分清单片机、CPU 和嵌入式系统；读懂 VDD/VSS/GND；能说明程序、数据与寄存器各放在哪里。

## 生活中的例子：自动洗手液机

传感器检测手靠近，控制芯片判断距离，电机推动泵，计时后停止。机器无需桌面、鼠标或显示器，也能运行程序。这种为特定设备服务的计算机系统叫**嵌入式系统**。机器人控制板也是如此。

**单片机（MCU）**把 CPU、存储器和多种外设放在同一芯片上。CPU 是计算和控制核心，不等于整颗单片机。嵌入式系统也可采用运行 Linux 的应用处理器，不是所有嵌入式系统都只有单片机。

## CPU、GPU、RAM、ROM、Flash 与 SSD

| 名称 | 通俗解释 | 断电后通常怎样 | 机器人中的例子 |
|---|---|---|---|
| CPU | 执行通用指令、控制流程的核心 | 需要重新启动 | 计算控制输出、处理通信 |
| GPU | 擅长大量并行计算的处理器 | 计算状态不靠它永久保存 | 上位机处理图像、模型计算 |
| RAM | 运行时工作台 | 常用 SRAM/DRAM 数据丢失 | 变量、栈、接收缓冲区 |
| ROM | 只读存储器这一类别或惯称 | 非易失 | 固化启动程序；不能把所有程序存储都当掩膜 ROM |
| Flash | 可擦写的非易失存储器 | 保留数据 | STM32 内部用户程序 |
| SSD | 由控制器、通常为 NAND Flash 等构成的存储设备 | 保留文件 | 电脑系统、模型和资料 |
| 寄存器 | CPU 内部或外设的少量状态/控制单元 | 通常复位或断电后变化 | GPIO 输出位、定时器计数值 |

Flash 是一种存储技术，SSD 是一个设备。STM32F107 内部 Flash 与电脑 SSD 的组织和接口不同，不能简单互换。

## 电压、电流与二进制

电压是两点之间的电势差，电流是电荷流动的速率。电阻在适用条件下满足 $V=IR$。例如 3.3 V 经 1 kΩ 电阻到地，理想电流约为 3.3 mA。LED 还有自身压降，计算限流电阻时需要扣除。

数字电路用两个电压范围代表逻辑 0 和 1。**高电平不是永远等于 5 V**，也不是“有电流就为 1”。输入高低阈值要查具体芯片数据手册，处于阈值间的电压不能可靠解释。

二进制 `00001010` 等于十进制 10。一个位可以表示开关，一个字节通常是 8 位。位运算适合表达“只改变这一盏灯，其他位保持原样”。

## 引脚上的 VDD、VSS、GND 是什么

| 标记 | 常见含义 | 接线理解 |
|---|---|---|
| VDD / VCC | 正电源标记，来源于不同器件传统 | 实际电压以手册为准，不能凭名字判断 |
| VSS / GND | 负电源端或电路参考地，单电源板上常相连 | 逻辑电压相对于这个参考点测量 |
| VDDA / VSSA | 模拟电源/参考地 | 按推荐电路去耦并妥善连接，不随意悬空 |
| VBAT | 备份域电源 | 是否另接电池取决于板级设计 |
| NRST | 低有效复位 | 拉低触发复位，接法按参考设计 |
| BOOT0 | 启动模式选择 | 与其他启动配置共同决定从哪里启动 |

GND 不必等于建筑物保护地或大地。当非隔离串口两块板通信时，通常要共地，使它们对“3.3 V”的理解一致。共地不代表可以把不兼容的电源输出直接短接。

<Figure name="power" caption="教学供电示意：电池经降压为逻辑供电；驱动器为电机供能；信号共地。实际额定电压与电流必须按模块核对。" />

降压模块把较高直流电压变为较低电压。开关型 Buck 通过开关、电感、电容转移能量；不是把多余电压简单变成热。必须核对输入范围、输出电流和纹波。GPIO 只能输出有限信号电流，不能直接给电机供电。

## 代码：用一个字节表达开关

```c
#include <stdint.h>
uint8_t lamps = 0x00;              // 所有位清零
lamps |= (uint8_t)(1U << 3);        // 第 3 位设为 1
lamps &= (uint8_t)~(1U << 3);       // 第 3 位清零
```

第 1 行提供固定宽度类型；第 2 行创建 8 位无符号变量；第 3 行先左移生成掩码再按位或；第 4 行对掩码取反后按位与，只清除所选位。这里操作的是 RAM 变量，尚未控制真实引脚。

## 常见错误

把电源标记当成电压值；把 Flash 当运行时 RAM；把 GPU 理解为所有任务都比 CPU 快；把单片机引脚直接接电机。

## 思考题与答案解析

<details><summary>程序断电还在，为什么变量计数又从零开始？</summary>程序通常保存在非易失 Flash，普通运行变量在 RAM，启动代码又会初始化它们。要跨断电保存计数，需要专门的非易失保存机制，并考虑写入寿命。</details>
<details><summary>两块板的 TX/RX 接对了却通信不稳定，为什么要检查 GND？</summary>非隔离电平信号依赖共同参考。没有合适参考时，接收器看到的电压可能落在错误范围。还要检查电平兼容、波特率和线缆。</details>
