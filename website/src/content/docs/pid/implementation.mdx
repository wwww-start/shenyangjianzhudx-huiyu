## 学习目标与生活例子

学会区分“这次一共用多少力”和“比上次多用多少力”，并解释为什么油门到底后不能继续累积欠账。前者对应位置式，后者对应增量式。

## 位置式 PID

“位置式”不是只能控制位置，而是直接计算本次绝对输出：

$$u_k=P_k+I_k+D_k$$

原仓库的 `pid.c` 就是位置式，可以用于速度等被控量。状态包括积分、上次测量、滤波微分；控制器使用前必须成功初始化。

## 测量值微分：避免给定阶跃冲击

目标从 0 跳到 60 时，对误差求差分会看到一次很大的跳变，即使电机还没动。改为对测量值求微分：

$$D_k^{raw}=-K_d\frac{y_k-y_{k-1}}{T_s}$$

负号来自误差 $e=r-y$。当目标固定时，它与误差微分一致；目标变化时两者不同。这是一种设定值加权思路，P 项仍会对目标变化立即响应。第一次采样没有上一测量，示例将原始微分置零。

## 微分滤波

$$\alpha=\frac{T_s}{\tau+T_s},\qquad D_k=D_{k-1}+\alpha(D_k^{raw}-D_{k-1})$$

实验取 $T_s=0.01$ s、$\tau=0.03$ s，所以每次向新差分值靠近四分之一。较大的滤波时间常数能抑制快速噪声，也带来滞后。滤波不是把数据错误“修好”，编码器异常仍要单独处理。

## 输出限幅和条件积分

$$u_k^{out}=\operatorname{clip}(u_k,0,1)$$

电机驱动不可能提供 160% 占空比。只截断输出还不够：若积分继续累积，目标降低后可能很久都降不下来，这叫积分饱和。

本例先计算候选积分并限制到 ±0.8，再试算总输出。如果试算输出大于 1 且误差仍为正，或者小于 0 且误差仍为负，就拒绝这一步积分；误差帮助输出脱离饱和时允许积分更新。这就是**条件积分**。实验关闭该选项时，±0.8 积分硬限幅仍保留。

## 增量式 PID：计算变化量

对未滤波、误差微分、无饱和的标准位置式前后两次相减，可得：

$$\Delta u_k=K_p(e_k-e_{k-1})+K_iT_se_k+\frac{K_d}{T_s}(e_k-2e_{k-1}+e_{k-2})$$
$$u_k=u_{k-1}+\Delta u_k$$

这个常见公式不能直接冒充带测量微分、微分滤波和条件积分的实现。为与原代码公平比较，本网站使用更一般的差分形式：

$$\Delta u_k=(P_k-P_{k-1})+(I_k-I_{k-1})+(D_k-D_{k-1})$$

内部累积的是**未限幅总输出**，最终再限幅；I、D 状态与位置式完全一致。初值相同时，两种形式在本实验中给出相同曲线，仅计算组织方式不同。若改用“上次已限幅输出”累加，就引入了另一种饱和跟踪策略，不能再宣称无条件等价。

```c
/* 教学片段：P/I/D 已按同一策略计算，所有 old_* 初始为 0 */
float delta = (P - old_P) + (I - old_I) + (D - old_D);
raw_output += delta;              /* 累加到未限幅输出 */
float output = clamp(raw_output, 0.0f, 1.0f);
old_P = P; old_I = I; old_D = D;  /* 供下次差分 */
```

第 1 行对每个分量作差；第 2 行累积变化；第 3 行遵守执行器限制；第 4 行保存历史。这个片段用于说明组织方式，不是替换原 C 接口的完整驱动程序。

| 比较 | 位置式 | 增量式 |
|---|---|---|
| 主要结果 | 本次输出 u | 本次变化 Δu |
| 保存状态 | I、微分等 | 历史分量和输出累积状态 |
| 积分饱和 | 需要显式处理 | 同样需要明确策略 |
| 切换控制器 | 需要对齐状态 | 也要对齐初始输出，避免跳变 |
| 本实验曲线 | 基准 | 同初值和同策略时与基准重合 |

## 调参顺序与常见错误

先验证电机方向、编码器符号和固定采样，再从小 P、零 I/D 开始；逐步提高 P 观察响应，加入少量 I 减小偏差，必要时加带滤波的 D。每次只改一项，记录曲线。实际电机还需电流、温度、失速和传感器故障处理，仿真中没有这些约束。

不要把别人的 Kp 直接抄到不同单位的系统；不要以为增量式天然抗饱和；不要在通信阻塞的主循环中假装采样周期恒定。

## 思考题与答案解析

<details><summary>切换为增量式后，曲线为什么没有变化？</summary>本实验将相同 P/I/D 状态差分后累加，且未限幅输出初值一致。从代数上应恢复相同总和。不同结果不应靠人为编造，而应来自真实的策略、初值或数值精度差异。</details>
<details><summary>目标设为 120，实际长期不到 120，一定是 Ki 太小吗？</summary>不是。4 s 后模型稳态最大速度为 90×1=90，目标不可达。增加积分无法突破输出上限；应检查可达目标和对象能力。</details>
