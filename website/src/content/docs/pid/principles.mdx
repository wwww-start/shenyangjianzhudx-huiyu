## 学习目标

能画出速度闭环，解释目标、测量与误差；理解 P、I、D 分别利用了什么信息；区分超调、振荡和稳态误差。

## 生活中的例子：骑车上坡

在平路固定踩踏力度，速度可能稳定。上坡后阻力变大，相同力度却变慢。如果你看着速度表，发现太慢就多用力，接近目标便收力，你就在使用反馈。

**开环**只按指令给输出，例如固定 60% 占空比。**闭环**还测量结果，根据偏差修正输出。闭环能减小某些扰动影响，但传感器接反、延迟过大、参数过激也会使它不稳定。

## 基础概念与连续公式

先统一单位：本课速度用教学单位，时间用秒，输出用 0～1 的占空比比例。误差定义为 $e(t)=r(t)-y(t)$。

$$u(t)=K_p e(t)+K_i\int_0^t e(\tau)\,d\tau+K_d\frac{de(t)}{dt}$$

这是一种并联形式。另一些教材使用 $K_p,T_i,T_d$，换算为 $K_i=K_p/T_i$、$K_d=K_pT_d$，不能直接混抄数值。输出无量纲时，三个增益的量纲也不同。

### P：看现在差多少

误差大就多输出。例如 $K_p=0.01$、目标 60、实际 40，则 P 项为 0.2。只有 P 时，系统往往需要保留一点误差才能维持非零驱动力。增大 P 一般加快响应，但存在惯性、延迟时可能导致超调或振荡，并非越大越好。

### I：记住过去欠了多少

即使每次只差一点，积分也会逐步累积修正量。因此系统在误差接近零时仍可保留维持转速所需的输出。积分消除的是适用条件下的稳态误差；目标超过电机能力时，再大积分也不能创造额外电压。

### D：看变化有多快

如果实际速度正在快速上升，测量值微分会产生负向作用，帮助提前减小输出。D 不会预知未来，而是使用最近采样之间的变化趋势。差分也会放大高频噪声，因此需要滤波，并非每个速度环都必须加 D；实践中 PI 很常见。

## 连续到离散：每 10 ms 算一次

$$e_k=r_k-y_k,\qquad I_k=I_{k-1}+K_iT_se_k$$
$$P_k=K_pe_k,\qquad D_k^{\mathrm{error}}=K_d\frac{e_k-e_{k-1}}{T_s}$$

其中 $T_s=0.01\,\mathrm{s}$。改变采样周期时，积分要乘新的周期，微分要除新的周期。如果只把控制函数调用频率翻倍却不更新计算，控制器含义就变了。

## 怎样读响应曲线

| 指标 | 在图上找什么 | 常见解释 |
|---|---|---|
| 上升过程 | 实际值向目标靠近的速度 | 增益、惯性与输出能力共同决定 |
| 超调 | 实际值超过目标的最大程度 | 控制过激、积分积累或阻尼不足 |
| 稳态误差 | 充分稳定后目标与实际的差 | 仅 P、饱和或偏置均可能造成 |
| 振荡 | 误差反复正负变化 | 参数、时延、噪声、离散化都需检查 |

一次有限时长仿真中的最终误差，不一定就是稳态误差。实验会明确显示观测窗口。

## 代码：计算一次比例输出

```c
float target = 60.0f;                 // 1：设定目标
float measured = 40.0f;               // 2：读取或代入测量值
float error = target - measured;      // 3：明确误差方向
float output = 0.01f * error;         // 4：比例计算，得到 0.2
```

第 1、2 行必须使用相同单位；第 3 行若方向反了，负反馈可能变成正反馈；第 4 行只是 P 项，不含完整的限幅与异常处理。下一课直接阅读原仓库完整控制器。

## 常见错误

- 用 PWM 百分比当作测得速度。占空比是输入，速度是结果。
- 把 D 称为预测器，忽略测量噪声与采样时间。
- 看到 8 s 末端接近目标，就断言系统在所有条件下稳定。

## 思考题与答案解析

<details><summary>为什么只有 P 时，小车可能总比目标慢一点？</summary>电机维持转速需要非零输出。P 输出等于 Kp×误差；如果误差严格为零，P 输出也为零。稳态时常需要保留误差来提供驱动力。前馈或积分可以提供额外的稳态输出。</details>
<details><summary>固定占空比加一个速度显示屏，就算闭环了吗？</summary>不算。测量必须参与下一次控制输出的计算；只显示结果仍是开环控制。</details>
