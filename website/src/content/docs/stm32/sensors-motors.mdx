## 学习目标与生活例子

一辆小车需要“感觉器官、传话方式和肌肉”：ADC 读取模拟传感器，UART/CAN 传递数据，驱动器向电机供能，编码器反馈运动结果。学会把这些环节连接成可检查的工程。

## ADC：把连续电压变成数字

F107 的 ADC 为 12 位。理想情况下，在参考电压范围内可用 $V\approx code\times V_{ref}/4095$ 进行端点换算，量化步距约为 $V_{ref}/4096$。真实结果还受参考电压误差、噪声、输入阻抗、采样时间和校准影响。

例如电位器输出接 ADC 后，先配置模拟输入、ADC 时钟与通道/采样时间，按手册执行校准，再触发转换并读取结果。信号不得超出引脚允许范围；高源阻抗时采样时间太短会使内部采样电容充电不足。

## UART：先约定节奏，再发送字节

异步串口双方需要一致的波特率、数据位、校验和停止位。TX 接对方 RX，电平兼容且有适当参考地。UART 字节流没有天然的“完整命令”边界，因此协议常加入帧头、长度、校验和或 CRC。

```c
/* 字节流处理思路：每收到一个字节才推进一次解析状态 */
switch (state) {
case WAIT_HEADER: /* 若为帧头，转到读取长度 */ break;
case READ_LENGTH: /* 检查长度不超过缓冲区 */ break;
case READ_DATA:   /* 收集数据，到齐后校验 */ break;
}
```

第 1 行依据当前状态分流；等待帧头使解析器能重新同步；长度检查防止越界；数据阶段不能假定一次接收就得到整帧。完整原示例在 `examples/protocol/frame_parser.c`，可从资源页打开。

## CAN：控制器与收发器不是同一个东西

CAN 控制器组织帧、仲裁和错误处理；外部 CAN 收发器把逻辑信号变成总线差分信号。多个节点共享总线，仲裁基于标识符等字段，不是每个节点想发就强行驱动。经典 CAN 数据帧的数据字段最多 8 字节，不能与 CAN FD 混淆。

总线拓扑、两端终端匹配、电源和参考地/隔离方案都影响可靠性。开发板标有 CAN_TX/CAN_RX 不意味着可以直接接 CAN_H/CAN_L。教学先发送固定帧，再检查标识符、字节序、量纲和更新周期。

## 编码器：从脉冲到速度

增量式正交编码器 A/B 两路相位不同，可判断方向；定时器编码器模式可计数。若每转在所选倍频与减速比下对应 $N$ 个有效计数，则：

$$n_{rpm}=\frac{\Delta count}{N}\frac{60}{T_s}$$

必须明确 N 是电机轴还是输出轴的计数。计数溢出要按计数器位宽处理；低速时固定时间窗内脉冲太少会产生量化波动，必要时考虑周期测量或更长观测窗口。

## 电机、TB6612 与步进电机

<Figure name="motor" caption="电机速度闭环：编码器计数换算速度，定时 PID 产生控制量，经驱动器作用于电机，再反馈到下一次采样。" />

TB6612FNG 是双路全桥驱动器，常用于两路有刷直流电机。方向引脚决定桥臂状态，PWM 改变驱动过程，STBY 控制待机。电机电源与逻辑电源要分别按手册核对。

“TB6612 步进电机”不能作为一种电机名称。双 H 桥在适当接法和相序下能驱动一台双极步进电机，但 TB6612 不等同于带可调恒流斩波、细分控制的专用步进驱动器。步进电机依次励磁产生步进运动；开环脉冲数量不保证永不丢步，负载过大时需要反馈或重新定位。

H 桥的四个开关用来改变电机两端电压方向；**惠斯通电桥**则是电阻桥式测量电路，用于检测电阻变化。二者名字都有“桥”，功能完全不同。

## 把模块连接起来

固定周期读取编码器 → 换算速度 → 校验测量 → 调用 PID → 限制控制输出 → 更新方向与 PWM。通信任务只更新目标值，不能随意改变控制采样间隔。主循环管理状态，中断完成短小、必要的定时工作；开始和故障状态都应有明确输出。

## 常见错误与思考题

忘记 STBY、把 5 V 信号接到不容忍的引脚、把电机电流流经细信号地、倍频计数搞错、传感器方向相反，都会造成“代码看起来没问题却不工作”。

<details><summary>每输出轴一转有效计数 1200，10 ms 内增量 12，转速多少？</summary>12÷1200×60÷0.01=60 rpm。若 1200 是电机轴数据而非输出轴数据，还需按减速比换算。</details>
<details><summary>为什么不能直接把 PID 输出当作 PWM 寄存器值？</summary>输出可能采用 0～1 或带符号的归一化量；CCR 使用计数单位。必须明确方向、缩放、限幅与零输出行为。</details>
