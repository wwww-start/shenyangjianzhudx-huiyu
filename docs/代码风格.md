# 示例代码风格

标准库示例参考用户提供的江协科技代码标准，以 User、Hardware、System 划分目录；同一模块使用同名 .c/.h，公开函数使用 Module_Function，内部状态使用 static。采用四空格缩进、独立行花括号和中文解释性注释。

用户提供的规范包含 STM32F407 项目背景。本培训沿用其组织与书写风格，硬件与 API 使用 STM32F107 和 STM32F10x 标准外设库，不混用 F4 库或 HAL。代码是独立编写的教学示例，不声称为江协科技官方代码。

头文件使用防重复包含保护，公开接口有声明，源文件包含自身头文件。初始化显式配置结构体、时钟和引脚。调用者应检查有返回值的初始化与转换函数。桌面端已有示例接口保持稳定。
